## 🚀 Quick Launch & Local Preview

### Option 1: Direct Browser Launch (Instant)
Simply open `index.html` directly in Google Chrome, Microsoft Edge, or Mozilla Firefox. The Three.js 3D engine, icons, and fonts will load immediately.

### Option 2: Local Static Server (Python / Node)
```bash
# In the project directory:
python -m http.server 3000
# or:
npx serve .
```
Navigate to `http://localhost:3000` in your browser.

### Option 3: Full React + Vite Development
```bash
npm install
npm run dev
```

## 🌐 Deployment Instructions

### Deploy to Vercel (Recommended)
1. Push this folder to a GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of Dillu 3D Developer Portfolio"
   git branch -M main
   git remote add origin https://github.com/dilluthecoder/<new-repo-name>.git
   git push -u origin main
   ```
2. Go to [Vercel](https://vercel.com) and import the repository.
3. Framework Preset: **Vite** (or Static).
4. Click **Deploy**. Vercel will build and assign a global CDN URL within seconds.

### Deploy to GitHub Pages
1. In repository settings on GitHub, navigate to **Pages**.
2. Under **Build and deployment**, set the source to **Deploy from a branch**.
3. Select `main` branch and `/ (root)` folder.
4. Click **Save**. The website will be live at `https://dilluthecoder.github.io/<new-repo-name>/`.
